# Five Night's at Sonic's (HaxeFlixel)

![fnascover](https://files.catbox.moe/cyl12k.png)

# About

A port of Five Nights at Sonic's to the HaxeFlixel game engine.
Specifically, this is the original 1.0 release of the game, not 2.0.

# Notes

This port does not attempt to be 100% accurate.

All enemy AI difficulty and movement is done by pure guesswork
and is also balanced based off these guesses.
